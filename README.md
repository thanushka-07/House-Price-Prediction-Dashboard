# House-Price-Prediction-Dashboard
A Data Analytics dashboard for analyzing and predicting house prices using data visualization.
## Project Overview
The House Price Prediction Dashboard provides an interactive view of house price data using Power BI. It helps users explore house prices based on different attributes and understand patterns and trends through visualizations.
The dashboard converts raw house data into meaningful insights using data cleaning, analysis, and interactive visualizations.
## Tools & Technologies
- Power BI
- Power Query
- Data Visualization
- Data Cleaning
- Data Analysis
- DAX
## Dashboard Features
- Interactive dashboard
- House price analysis
- Price comparison across different categories
- Interactive slicers and filters
- Data-driven visualizations
- Easy-to-understand KPIs
- Identification of important patterns and trends
## Key Analysis
The dashboard helps analyze:
- House prices
- Property characteristics
- Price variations
- Category-wise comparisons
- Trends and patterns in house prices
